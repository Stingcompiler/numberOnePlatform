# أصول متجر Google Play

| الملف | المقاس | الاستخدام |
|---|---|---|
| `feature-graphic.png` | 1024×500 | Feature Graphic (إلزامي) |
| `01-login.png` | 1200×2400 | لقطة: تسجيل الدخول |
| `02-home.png` | 1200×2400 | لقطة: الشاشة الرئيسية |
| `03-courses.png` | 1200×2400 | لقطة: المقررات الدراسية |
| `04-course.png` | 1200×2400 | لقطة: تفاصيل مقرر |

كل اللقطات بنسبة 2:1 بالضبط (حدّ Play الأقصى)، وبصيغة PNG بلا شفافية.
اللقطة الأصلية كانت 1080×2400 (نسبة 2.22:1) وهي مرفوضة، فأُضيفت هوامش
جانبية بلون خلفية التطبيق بدل قصّ المحتوى.

## ملاحظة خصوصية
لقطة `02-home.png` أُخذت من حساب طالب حقيقي، واسمه **مطموس** في الصورة
النهائية. راجع أي لقطة جديدة قبل رفعها للمتجر.

## كيف أُخذت
عبر profile مخصص في eas.json اسمه `screenshots` يُفعّل متغيّرين:
`EXPO_PUBLIC_ALLOW_EMULATOR` و`EXPO_PUBLIC_ALLOW_CAPTURE`.
هذا البناء يُعطّل حماية المحتوى (FLAG_SECURE) — **لا يُوزَّع على الطلاب**.
بناءات `preview` و`production` تبقى محمية بالكامل.
